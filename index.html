Features

Everything you need to spice up your voice

A complete soundboard experience — built with Web Audio API and Electron.

25+ Built-in Sounds

Drums, effects, UI sounds, audience reactions, and musical notes — all synthesized in real-time. No external files needed.

Global Hotkeys

Assign any key combination (F1, Ctrl+G, Alt+1, Shift+Mouse...) and trigger sounds even when minimized or in fullscreen games.

Microphone Recording

Record from your microphone, trim and normalize with the built-in editor, then add it to your soundboard.

Upload & Edit

Import MP3, WAV, OGG files. Cut, trim, and normalize volume with the visual waveform editor.

3 Play Modes

Switch between speakers-only, microphone-only, or both. Perfect for testing sounds before sharing.

System Tray

Minimize to system tray and keep hotkeys active in the background. Lightweight on CPU and memory.

Repeat & Continue

Loop a single sound infinitely, or play your sound list sequentially like a media player.

Categories & Hotbar

Organize sounds into custom categories. Pin your favorites to the 12-slot hotbar for instant access.

Installation

Get started in minutes

Choose your preferred method. Pre-built installer is the easiest.

1

Download the installer

Grab the latest SoundPad-Studio-1.0.0.exe from GitHub Releases. NSIS installer (recommended) or portable version.

→ Go to Downloads

2

Run the installer

Double-click the .exe file. Choose install location (or just use portable .exe directly without installation).

3

Launch SoundPad Studio

Find it in your Start Menu or on your Desktop. An icon will also appear in your system tray.

4

Assign hotkeys

Right-click any sound in the list to assign a global hotkey (e.g. Ctrl+F1, Alt+1).

1

Install prerequisites

Install Node.js 20+ from nodejs.org. Also install Python 3 (for icon generation, optional).

2

Clone the repository

git clone https://github.com/unknown404esp-glitch/soundPad.git

cd soundPad

3

Run the build script

Double-click build-exe.bat (Windows) or run:

npm install
npm run build:exe

4

Find your .exe

After 5-15 minutes, the executable appears in the dist/ folder.

1

Install VB-CABLE (free)

Download from vb-audio.com/Cable. Extract, right-click VBCABLE_Setup_x64.exe → Run as administrator → Install. Restart your PC.

2

Set Windows output to CABLE Input

Right-click the speaker icon in taskbar → Sound settings → Output device → CABLE Input (VB-Audio Virtual Cable)

3

Set Discord/Game input to CABLE Output

In Discord: Settings → Voice & Video → Input device → CABLE Output (VB-Audio Virtual Cable)

4

Test it

Open SoundPad Studio, set the play mode to "Both" or "Microphone" in the toolbar, and click a sound. Your friends in Discord will hear it.

FAQ

Frequently asked questions

Got more questions? Open an issue on GitHub.

Is it really free? +
Yes. SoundPad Studio is 100% free and open-source under the MIT license. No ads, no telemetry, no in-app purchases. You can use it, modify it, and distribute it freely.
Why don't my friends hear the sounds? +
Browsers and Electron cannot send audio directly to your system microphone input for security reasons. You need a Virtual Audio Cable (VB-CABLE) — see the Installation tab "Audio Routing" for step-by-step instructions. It's free and takes 5 minutes.
Do hotkeys work when minimized or in fullscreen games? +
Yes — the desktop .exe version uses Electron's globalShortcut API, which works at the OS level. Hotkeys work even when the app is minimized to system tray or when you're in a fullscreen game. (The web demo version only supports hotkeys when the browser tab is focused.)
What audio formats are supported? +
You can upload MP3, WAV, OGG, FLAC, M4A, and WebM files. The app uses the browser's native audio decoding, so any format your browser supports will work.
Is there a Mac or Linux version? +
The web demo (index.html) works on any OS. The desktop .exe is currently Windows-only, but the codebase is cross-platform — community contributions for macOS/Linux builds are welcome!
Can I use this for streaming on Twitch/YouTube? +
Absolutely. Use "Listen to this device" in Windows Sound settings to route the CABLE Output back to your speakers. Then in OBS, add a new Audio Input Capture source and select "CABLE Output". Your viewers will hear the sounds while you do too.
My antivirus flags the .exe as suspicious. Why? +
This is a false positive. Electron apps without a paid code-signing certificate often get flagged. The code is open-source — you can review every line and build it yourself from source. To suppress the warning, add the dist folder to your antivirus exclusions.
How do I report a bug or request a feature? +
Open an issue on our GitHub repository. Please include: your OS version, the app version, steps to reproduce, and any error messages. We respond to most issues within 48 hours.
